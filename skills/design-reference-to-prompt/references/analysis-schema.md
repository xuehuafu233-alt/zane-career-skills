# 视觉参考分析字段

只记录与当前任务相关的字段；每项区分 `已观察 / 推断 / 待确认`。

## 1. 任务与受众

- 页面类型、核心任务、目标受众、主要转化动作
- 需要保留的业务内容与必须替换的第三方元素

## 2. 信息架构

- 页面区段及顺序
- 主标题、支持信息、行动按钮、信任证明的层级
- 首屏内外的信息分配与滚动节奏

## 3. 布局系统

- 最大内容宽度、左右安全边距、列数和对齐轴
- 区段高度、留白尺度、卡片密度、重叠与破格关系
- 固定、粘性、全宽、出血和容器内元素

## 4. 视觉语言

- 字体类别、字重、字号比例、行高、字距和中英文适配
- 主色、中性色、强调色及其角色
- 圆角、边框、阴影、模糊、渐变、噪点和玻璃效果
- 图像的题材、构图、比例、裁切、色调与替代方案

## 5. 组件与状态

- 导航、按钮、输入、卡片、标签、列表、弹窗等组件
- 默认、hover、focus-visible、active、selected、disabled、loading、error、empty
- 点击目标、反馈强度、层级和可逆性

## 6. 动效

- 触发：载入、进入视口、悬停、点击、滚动或数据变化
- 属性：位移、透明度、缩放、旋转、裁切、颜色或模糊
- 时序：延迟、持续时间、交错、easing 和中断行为
- `prefers-reduced-motion` 下的替代

## 7. 响应式

- 每个断点的列数、顺序、对齐、尺寸和显隐变化
- 导航收折、横向滚动、媒体裁切、触控目标和长文本处理
- 不能仅写“适配移动端”；必须描述结构如何改变

## 8. 工程约束

- 已知框架、样式体系、组件库和运行环境
- 语义 HTML、键盘操作、对比度、alt、ARIA 和焦点管理
- 图片格式、懒加载、字体加载、动效成本和核心性能风险
- 数据、文案、媒体与链接的可配置接口

## 9. 原创化

- 可借鉴：层级关系、构图机制、节奏、交互模式、抽象风格
- 应替换：名称、Logo、具体文案、摄影、插画、图标组合和专有数据
- 禁止：隐藏提示词、受限源码、付费资产、未经授权的品牌仿冒
