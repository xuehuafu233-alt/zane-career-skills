# 方法来源

本验收法来自作品集网站、知识库、Word／PDF 简历与信息图的多轮真实发布流程。其关键不是通用“检查响应式”，而是把招聘判断、证据权重、图文增量、生成源一致性和公开风险放在同一张发布清单中。

多轮发布复查暴露了四类问题：简历与网站可能使用不同时间快照；二维码源图正确但必须在最终 PDF 里重新解码；可见 URL 不等于 PDF 存在链接注释；动作截止日与结果数据日不同，不能把更晚的完整动作写成更早结果的单一原因。新增门槛来自真实复查，不是通用模板扩写。

后续多语言上线进一步暴露：固定中文坐标不能直接承载英文；静态渲染通过不等于目标浏览器通过；上传成功不等于线上关键资源正确；工具显示的浏览器名称也不等于用户实际看到的应用。因而加入图形内部边界、真实应用身份、缓存破坏与线上文件一致性四类验收。

线上复查还发现，托管平台可能规范化HTML链接而保持正文与资源正确。因而v0.7把“线上一致性”拆成两类：未被改写的静态资源继续做字节／哈希比对；被平台后处理的HTML改做关键正文与结构命中、旧版本清除、真实交互和发布标识验证。既不把预期平台改写误报为失败，也不因为HTTP 200而放弃版本核对。
