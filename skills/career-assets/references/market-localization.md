# 目标市场适配协议

不要在通用 Skill 中内置某个国家、职位或语言的固定简历模板。每个目标市场单独确认或研究：

1. 岗位名称与级别在当地招聘语境中的含义；
2. 主要招聘者、常用投递渠道与真实截断规则；
3. 简历页数、个人信息、照片、日期与联系方式习惯；
4. 行业术语、品牌官方名称、法定主体和指标解释；
5. 作品集是否常见、何种证据能建立信任；
6. 语言读者对句式、标签、序号、语气和管理表达的预期；
7. 隐私、前雇主数据、签证或工作授权等必要边界。

动态规范优先使用当前官方招聘平台、目标公司岗位样本和当地可信招聘来源验证。无法验证时标记假设，不把通用英语习惯冒充特定市场规则。

输出市场合同：`已验证规则 / 仅为样本趋势 / 当前假设 / 对简历的影响 / 对网站的影响 / 待用户确认`。
