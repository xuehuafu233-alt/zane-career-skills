# Career Application Greeting

打招呼语是投递链路的连接器，不是第三份简历。它读取共享事实与主张图，只选择当前岗位最相关的一条路径：为什么联系 → 哪项价值相关 → 哪个证据值得打开。

本 Skill 只负责当前首条消息的生成与校准，不把面试、谈薪、入职或完整风险审计提前塞进首触点；消息生成后是否发送，按现实介入规则单独判断。

## 1. Define

读取目标岗位、招聘者身份、投递方式、可见字符限制（只有真实平台证据时才使用固定字符预算）、候选人定位、简历与作品集入口。若缺少岗位信息，不用抽象“个人优势”填空；先基于已有事实给出低风险版本并标记假设。

把三种文本分开：

- 招呼语：当前岗位的相关性 + 一个证据钩子 + 下一步；
- 简历：价值判断、职责、结果和经历证据；
- 作品集：判断、取舍、现场、边界和深读证据。

## 2. Write

- 先说联系原因，再说一项最相关的价值，最后给出低压力的阅读路径；
- 只使用一个主张和一个证据锚点，避免一条消息塞入品牌、增长、AI、团队和跨界五套标签；
- 让记忆点来自真实判断或结果，不写“我就是……”“我相信……”式宣言，不制造金句；
- 不把简历中已经完整呈现的团队规模、管理年限和所有数字再抄一遍；
- HR 可能不懂专业词，先用业务语言，专业缩写只在能提高识别度时出现；
- 语气主动但不自夸：`我看到岗位需要 X，我过去在 Y 场景解决过相近问题，简历/案例里有一页证据可供参考`；
- 结尾不强行索取“请查收并回复”，给出可执行、低压力的下一步。

如果一句话在简历和作品集已完整出现，招呼语只做指向，不重复论证。若没有岗位 JD 或招聘者信息，明确使用哪个假设，不用候选人的全部定位填满空缺。

## 3. Language and links

中文可以保留自然称呼和平台语境，但不能写成模板化“您好，我有多年经验，符合贵司要求”。英文要重写为自然商业英语，不把中文敬语、并列标签或“希望有机会”逐字搬过去；可用 `I noticed...`, `My recent work...`, `I’ve attached...` 等清晰连接。

如果简历和作品集有不同语言版本，按读者语言给入口：中文读者指向域名根路径 `/`，英文读者指向同域名 `/en/`。不要让英文招呼语打开中文默认首页。

## 4. Quality gate

逐项检查：

1. 第一行是否说明为什么联系，而不是只有姓名和年限；
2. 是否增加了简历或作品集没有的新判断，而非重复四项优势；
3. 是否只有一个清晰证据锚点，且主体、时间和归因没有夸大；
4. HR 不懂专业词时，是否仍能理解业务价值；
5. 读完后是否知道下一步打开简历、作品集或回复什么；
6. 中文、英文和不同岗位版本是否分别校验语气与链接；
7. 没有凭“22字”或任何平台字符数做无证据断言。

## 5. Output

默认只输出当前消息所需的内容：

- 推荐版：一条可直接发送的文本；
- 选择理由：它承担的招聘任务和唯一证据锚点；
- 入口检查：仅当存在简历／作品集链接或语言路径需要核对时输出；
- 风险提示：仅当真实不确定性会改变发送动作时输出；没有这类不确定性就不输出该段。

需要多版本时，最多给三种：中文主动投递、中文猎头/HR回复、英文主动投递。每版只改语气和入口，不改事实。详细合同见 [references/contract.md](references/contract.md)。
