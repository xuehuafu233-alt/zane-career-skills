# 简历视觉人格生成

## 输入

从五类材料提取设计约束：目标岗位如何建立信任；候选人的工作气质；内容是数据、作品、技术还是关系驱动；可用照片与作品资产；用户喜欢和明确排斥什么。

不要只问“喜欢什么颜色”。让用户在具体对照中选择：克制或外放、编辑感或系统感、温暖或冷静、作品主导或文字主导、传统可信或前沿实验。记录选择理由，不机械采用用户给出的解决方案。

## 视觉指纹

生成一份项目配置：

- 3—5 个视觉性格词；
- 3—5 个反向禁区；
- 信息密度与留白倾向；
- 字体气质与中英文需求；
- 色彩角色，而非预设色值；
- 照片、图标、线条、卡片和数据的使用边界；
- 打印、屏幕与招聘平台限制。

## 候选方向

至少提供两种关系机制不同的方向，例如“编辑式长线阅读”和“系统式证据扫描”，不能只换颜色。每种方向说明为什么属于此人、牺牲了什么、在哪种招聘场景可能失效。

## 反模板测试

不要只拿完全不同职业做替换测试；差异过大时任何通用模板都容易自证“不能套”。构造一个最近邻反例：同一岗位层级或相近证据形态，但信任机制、职业阶段、渠道或资产不同的候选人。若只换文案与强调色，入口形态、首个证据、主阅读轴、经历组织、数字角色和收束方式仍成立，说明方案过于通用。

在合同中写下当前方向的六项结构签名。常见组合如“大字定位 → 横向数字带 → 分栏主案例 → 卡片经历”不是禁用项，但不能仅凭换行业就通过；必须说明每一段为何比无数字带、无 hero 或另一阅读轴的候选方向更适合当前证据。回到证据形态、工作气质或真实资产增加专属性，而不是继续换色。

不以“独特”为名牺牲扫读、打印、链接和事实可信度。
