# Zane Career Skills

Zane 的可复用职业资产 Skills。它们来自真实的简历、作品集、案例深读、双语本地化和多格式交付实践，但不包含个人资料、固定页面模板或私有工作台规则。

## 安装

```bash
npx -y skills add xuehuafu233-alt/zane-career-skills -g --all
```

安装后可按需使用 `zane-career-assets`、`zane-career-resume-builder`、`zane-career-portfolio-builder`、`zane-career-portfolio-website-design` 等 Skill。所有公开 Skill 目录均以 `zane-` 开头，便于识别来源。

## 包含内容

- `zane-career-assets`：职业资产总控
- `zane-career-portfolio-builder`：从零构建职业资产系统
- `zane-career-resume-builder`：多语言简历构建
- `zane-career-portfolio-website-design`：个性化作品集网站
- `zane-career-portfolio-architecture`：网站、深读页与投递载体分工
- `zane-career-application-greeting`：招聘首条打招呼语
- `zane-career-case-editor-zh`：中文职业案例编辑
- `zane-evidence-weighted-case-storytelling`：证据权重案例叙事
- `zane-former-employer-data-redactor`：前雇主数据公开边界
- `zane-portfolio-multi-format-qa`：网页、PDF、Word 和链接验收
- `zane-design-reference-to-prompt`：视觉参考转原创开发提示词
- `zane-eastern-natural-light-cinema`：东方自然光生活影像方法

## 设计原则

这些 Skill 不会把用户套进 Zane 的履历、视觉或职业路径。它们只提供判断动作、证据边界、工作流和验收标准；用户的岗位目标、经历、审美、语言和交付形式由每次任务决定。
