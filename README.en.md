# Zane Career Skills v0.7 beta

> A reusable Skill library for building resumes, portfolios, case studies, and delivery assets from a person's own experience, evidence, career goal, language, and visual taste.

This is not a resume template or a fixed website theme. It preserves the reasoning methods: evidence-led positioning, cross-medium allocation, voice and taste preservation, localization, privacy boundaries, and release QA.

## Start here

- Full 0-to-1 career asset build: `skills/career-portfolio-builder`
- Natural-language routing: `skills/career-assets`
- Resume: `skills/career-resume-builder`
- Portfolio website: `skills/career-portfolio-website-design`
- Case evidence and editing: `skills/evidence-weighted-case-storytelling`, `skills/career-case-editor-zh`
- Release QA: `skills/portfolio-multi-format-qa`

Install the folders under `skills/` into the Skill path supported by your Agent. See [docs/install.md](docs/install.md) and [VERSION.md](VERSION.md).

## Boundaries

The package does not contain personal resumes, employer names, contact details, project metrics, private workbench paths, credentials, or third-party source Skills. It does not invent facts or claim that every user should receive the same structure, color, length, or page count.

Source and licensing notes are in [docs/provenance.md](docs/provenance.md).
