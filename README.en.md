# Zane Career Skills

Reusable career-asset Skills for resumes, portfolios, case studies, localization, visual references, and release QA.

## Install

```bash
npx -y skills add xuehuafu233-alt/zane-career-skills -g --all
```

Every public Skill directory starts with `zane-`, making the collection easy to recognize while keeping each capability independently usable.

These Skills provide decision methods, evidence boundaries, workflows, and QA gates. They do not ship Zane's personal materials, fixed portfolio templates, or private workbench rules.

See `docs/provenance.md` and `docs/skill-inventory.md` for scope and source notes.
